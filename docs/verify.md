# 검증 기록 (docs/verify.md)

모든 화면은 로컬 HTTP 서버(`python3 -m http.server 8800`)와
Chromium(headless, SwiftShader WebGL2)으로 재현했습니다.
실제 GPU 수치는 기기마다 다르므로 7주차 task2 는 기기에서 직접 측정해야 합니다.

## 2주차 — 변환 세 페이지

| 확인 | 방법 | 결과 |
|---|---|---|
| 회전→이동 순서가 행렬에 드러나는가 | `week2/order.html` 에서 θ=45°, x=2, z=0.5 로 두고 두 행렬을 비교 | `T·R` 의 이동열 (2.00, 0, 0.50), `R·T` 의 이동열 (1.06, 0, −1.77) 로 다름 |
| 실제 비율 수치 | `week2/scale.html` 1 AU=10, 과장 ×1 | 지구 반지름 0.000426 단위(=10/23,481), 화면에서는 점 |
| 위성 변환이 카메라와 무관 | `week2/satellite.html` 카메라 방위 40°→200° | 달 모델 행렬 두 번 읽기 결과 동일 |

## 3주차 — 떠 있는 공 / 살아 있는 행성

| 확인 | 방법 | 결과 |
|---|---|---|
| 원근 vs 직교 | `week3/task1.html` 상단 버튼 전환 | 원근에서는 거리에 따라 크기 변화, 직교에서는 불변 |
| 카메라 이동 | `자동 회전 켜기` | 시점이 돌아도 공/바닥의 모델 행렬·MVP 구조 유지 |
| 행렬 가독성 | 우측 `MVP 행렬` 패널 | 4행 × 4열로 읽을 수 있게 출력 |
| 하나의 셰이더로 두 행성 | `week3/task2.html` | 색·줄무늬·자전 속도가 uniform 만으로 갈림, 낮/밤 경계 확인 |

## 5주차 — Phong 과 세 광원
