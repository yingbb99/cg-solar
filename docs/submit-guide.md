# 제출 가이드 (처음부터 따라하기)

> 이 문서는 **손으로 따라 하는 순서서**입니다. 위에서부터 그대로 하면 됩니다.
> 명령은 검은 창(터미널)에 복사해 붙여 넣으면 됩니다.

## 0. 지금 가진 것

* 폴더 `cg-2026-solar/` — 파일 85개, 약 6 MB.
* 이 폴더 **안에** `index.html` 이 있어야 합니다. `cg-2026-solar/index.html` 이 맞고,
  `cg-2026-solar/cg-2026-solar/index.html` 처럼 한 겹 더 들어가 있으면 안 됩니다.

## 1. 내 컴퓨터에서 먼저 열어 보기

### 1-1. Python 이 있는 경우 (가장 쉬움)

1. `cg-2026-solar` 폴더를 연다.
2. 그 폴더에서 터미널을 연다.
   * Windows: 폴더 빈 곳에서 Shift + 우클릭 → "여기서 PowerShell 창 열기"
   * macOS: 폴더 우클릭 → "폴더에서 새로운 터미널 열기"
3. 아래 한 줄을 붙여 넣고 Enter:

```
python3 -m http.server 8000
```

Windows 에서 `python3` 가 없다고 나오면 `py -m http.server 8000` 또는 `python -m http.server 8000`.

4. 브라우저에서 `http://localhost:8000/index.html` 을 연다.
5. 확인: 태양과 행성들이 보이고, 오른쪽에 FPS·삼각형 수가 올라가면 성공.
6. 끌 때는 터미널에서 Ctrl + C.

### 1-2. VS Code 가 있는 경우

1. VS Code 로 `cg-2026-solar` 폴더를 연다.
2. 확장 "Live Server" 설치 → `index.html` 우클릭 → "Open with Live Server".

> 왜 서버가 필요한가: 텍스처·스크립트를 `file://` 로 열면 브라우저가 보안 때문에
> 파일 읽기를 막습니다(CORS). 그래서 반드시 http 주소로 엽니다.

## 2. GitHub 에 올리기 (계정이 없다면 2-1 부터)

### 2-1. 계정 만들기

1. `https://github.com` → **Sign up** → 이메일·비밀번호·사용자 이름 입력.
2. 사용자 이름은 나중에 주소가 되므로 짧은 영문으로(예: `mgchoi-cg`).
3. 이메일 인증까지 마친다.

### 2-2. 저장소 만들기

1. 로그인 후 오른쪽 위 **+** → **New repository**.
2. Repository name: `cg-solar` (영문 소문자, 공백 없이).
3. **Public** 선택(무료 Pages 를 쓰려면 공개여야 함).
4. README 추가 체크는 **하지 않는다**(우리 README 를 올릴 것이므로).
5. **Create repository**.

### 2-3. 파일 올리기 (웹 화면에서 드래그)

1. 새로 만든 저장소 화면에서 **uploading an existing file** 링크를 누른다.
2. 파일 탐색기에서 `cg-2026-solar` **폴더 안의 내용물 전체**(index.html, src, week2~week7,
   docs, images, assets, README.md)를 선택해 끌어다 놓는다.
   * 폴더 자체를 끌어다 놓아도 됩니다(안의 구조가 그대로 올라갑니다).
   * 한 번에 100개까지만 올라갑니다. 파일이 85개이므로 한 번에 될 수 있지만,
     실패하면 `src`·`week2`·`week3` 처럼 폴더 단위로 나눠서 여러 번 올리면 됩니다(각각 Commit).
3. 아래 **Commit changes** 초록 버튼을 누른다.
4. 저장소 첫 화면에 `index.html`, `src/`, `week7/` 이 보이면 성공.

### 2-4. Pages 켜기

1. 저장소 위쪽 **Settings** 탭 → 왼쪽 메뉴 **Pages**.
2. Source: **Deploy from a branch**.
3. Branch: **main**, 폴더: **/(root)** → **Save**.
4. 1~2분 기다린 뒤 같은 화면 위쪽에 `Your site is live at https://…` 주소가 뜬다.
5. 그 주소 + `/index.html` 을 열어 본다. 예: `https://mgchoi-cg.github.io/cg-solar/index.html`

> 주소가 404 이면: Settings → Pages 에서 branch 가 main 인지, 파일이 루트에 있는지 확인하고
> 2~3분 더 기다린다(첫 배포는 느리다).

## 3. 두 기기에서 성능 측정 (7주차 task2)

1. 배포 주소 뒤에 `/week7/task2.html` 을 붙여 **기기 1**(PC/노트북)에서 연다.
2. 화면 위 `자동 시작 설정:` 줄에 기기 이름·코어 수가 찍힌다. 이 줄을 캡처한다.
3. 설정을 과제 공통 조건으로 맞춘다:
   * 측정 해상도 **640 × 360**, Path 표본 **8개**, Path 최대 반사 **2회**, 고급 효과 **켬**.
4. **「세 방식 측정」** 버튼을 누르고 결과 표(Local / Ray tracing / Path tracing)가 나오면 캡처.
5. 같은 주소를 **기기 2**(휴대폰)에서 열고 2~4 를 반복한다(휴대폰은 가로로 돌려서).
6. 고부하 경계 찾기: 해상도 960 → 1280 → 1920, 표본 16 → 32, 반사를 3 → 4 로
   **한 항목씩** 올리면서 화면이 눈에 띄게 느려지는 지점을 적는다.
7. `week7/week7.md` 의 **「실기기 측정 (직접 채우기)」** 표에 숫자를 채운다.
   위쪽의 참고값 표(소프트웨어 렌더러 값)는 지운다.
8. 새로고침(F5)해서 `자동 시작 설정` 이 **같은 단계로 유지**되는지 확인하고 그 사실도 적는다.

> 측정값이 이상하게 크면(수백 ms) 브라우저가 GPU 를 안 쓰고 있는 경우다.
> `chrome://gpu` 에서 "Hardware accelerated" 를 확인하고, 노트북은 전원을 꽂아 측정한다.

## 5. 교수 앞에서 설명할 때 (자주 묻는 5개)

**Q1. 행성 크기가 실제 비율이 아닌 이유?**
> 실제 비율이면 지구가 점보다 작아 아무것도 안 보입니다. 그래서 두 모드를 두었습니다.
> 압축 모드는 `dist = 7 + 6.6·au^0.62`, `planetR = 0.75·√rE` 로 간격과 크기를 각각 압축했고,
> 실제 모드는 `1 AU = 10 단위`, `planetR = (3.2/109.2)·rE` 입니다. 버튼으로 전환합니다.

**Q2. 그림자는 어떻게 만들었나?**
> shadow map 이 아니라 셰이더 안에서 **그림자 광선**을 쏩니다. 교차점에서 태양 쪽으로
> 다시 광선을 보내 16개 구체와의 교차를 검사하고, 가려지면 확산광을 0으로 만듭니다.
> 교육용 근사라 비용이 낮고, 식 관측기의 일식·월식도 같은 원리입니다.

**Q3. 광선 추적은 어디서 하나?**
> 화면 전체를 하나의 쿼드로 덮고 프래그먼트 셰이더에서 픽셀마다 광선을 만듭니다
> (`cameraRay` → `traceScene` → `shade`). 구체 배열을 uniform 으로 넘기고,
> 픽셀당 표본 1~4개, 반사는 거울 1회까지 계산합니다.

**Q4. 기기별 설정은 어떻게 정하나?**
> GPU 이름·코어 수·메모리·모바일 여부로 기기 지문을 만들고 `localStorage` 에 단계를 저장합니다.
> 처음 보는 기기만 가장 가벼운 단계를 실제로 3회 재서, 픽셀 수·표본·반사 비율로 다른 단계
> 시간을 추정해 33 ms(30fps) 안에 들어오는 가장 높은 단계를 고릅니다.

**Q5. PBR 에서 어떤 항을 썼나?**
> D 는 GGX, G 는 Smith-Schlick, F 는 Schlick 입니다. 금속은 F0 를 base 색으로,
> 유전체는 0.04 로 두고, 금속에는 확산광을 곱하지 않습니다(1-metal).

## 6. 자주 나는 오류

| 증상 | 원인 | 해결 |
|---|---|---|
| 화면이 까맣다 | `file://` 로 열었다 | http 서버로 연다(1-1) |
| 404 | 파일이 루트가 아닌 하위 폴더에 올라감 | 저장소에서 `index.html` 을 루트로 옮긴다 |
| 사진 재질이 안 보인다 | `week6/assets/week06` 이 안 올라감 | 그 폴더를 다시 업로드 |
| Pages 주소가 안 뜬다 | branch 이름이 다름(master) | Settings → Pages 에서 branch 를 실제 이름으로 |
| 값이 너무 느리다 | GPU 미사용 | `chrome://gpu` 확인, 전원 연결, 다른 탭 닫기 |
