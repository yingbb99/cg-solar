2주차 과제 · 4×4 변환 세 페이지

각 페이지는 슬라이더 입력 → 즉시 실행 → 화면 변화 확인이 가능하고, 4×4 행렬을 읽을 수 있는 형태로 함께 보여 줍니다.

  1. 2-1 회전 → 이동 순서 : 같은 값, 다른 순서. M = T·R 과 M = R·T 를 나란히 출력.
  2. 2-2 실제 비율 : 1 AU 를 단위로 정하고 실제 반지름 비(AU/23,481)와 과장 배율을 비교.
  3. 2-3 위성 변환 : 달의 모델 행렬이 카메라 방위와 무관함을 두 번 읽어 확인.

공통 도구: common.js (렌더러 + 행렬 표). 행렬은 열 우선이며 오른쪽이 먼저 적용됩니다.
