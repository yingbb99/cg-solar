# 3주차 보고서 — 정점·카메라·보간·확산광

## 실습 1: 떠 있는 공과 바닥 (`week3/task1.html`)
* 정점/인덱스 배열로 만든 구(위도 28 × 경도 40)와 평면(쿼드 4정점).
* 모델·뷰·투영 행렬을 각각 만들고 MVP 를 화면에 **4행 4열로 출력**해 읽을 수 있게 했다.
* 절차적 텍스처: UV 로 만든 격자(`mod(floor(u·n)+floor(v·n),2)`)를 색에 곱했다.
* 확산광(Lambert) + 정반사(Phong) + 상수 환경광.
* 그림자는 구의 단면을 바닥에 원으로 투영해 알파 블렌딩으로 그렸다(shadow map 없이 교육용 근사).
* **원근/직교 전환**: `M.perspective(fov, aspect, …)` ↔ `M.ortho(l,r,b,t,…)`.
  직교로 바꾸면 카메라를 움직여도 공의 화면 크기가 변하지 않는다(과제 요구 3점 중 2점).
* **카메라 이동**: 드래그·휠 + `자동 회전` 토글. 이동 중에도 모델 행렬은 그대로이고
  뷰 행렬만 바뀐다는 것을 행렬 패널로 확인할 수 있다.

## 실습 2: 살아 있는 행성 (`week3/task2.html`)
* **셰이더는 하나**, 두 행성은 `uTint`(색)·`uKind`(암석/기체)·`uSpin`·`uSize` uniform 만 다르다.
* `uTime` 을 CPU 에서 넣어 자전과 공전을 진행시킨다. 행성 A 는 자전 1.0×, B 는 0.4×.
* 낮/밤: `dot(N, L)` 을 `smoothstep(-0.22, 0.28, …)` 로 부드럽게 만들어 터미네이터를 만든다.
* 절차적 표면: 기체 행성은 `sin(vUV.y*26 + noise)` 위도 줄무늬, 암석 행성은 두 옥타브 잡음의 합.
* 대기 산란(rim)과 정반사로 행성마다 다른 질감을 준다.
